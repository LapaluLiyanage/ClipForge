Helper isn't running

ClipForge needs its local helper to merge streams and encode audio. Start it, then hit retry.

  1. Open the core folder
  2. Double-click run.bat (Windows) or run ./run.sh
  3. Wait for Listening on http://127.0.0.1:8787

Missing requirement

    Reading video…

    Video and audio arrive as separate streams above 360p — the helper merges them with ffmpeg.

    Re-encoded from the source audio. Going above the source bitrate adds size, not quality.

    Uncompressed PCM — roughly 10 MB per minute at 16-bit/44.1 kHz.

    M4A and Opus keep the original stream where possible, so there's no quality loss.

    Settings

    YouTube changes how it serves streams every few weeks. If downloads start failing, update yt-dlp and restart the helper.
